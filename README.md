# CybersecurityAwarenessBot
1. Click Code > Download ZIP
2. Extract the ZIP file
3. Open the folder `CybersecurityAwarenessBot-main (1)` (File folder)
4. Inside it, open the INNER folder `CybersecurityAwarenessBot-main`
5. Double-click `CybersecurityAwarenessBot.csproj` to open in Visual Studio
6. Press F5 to run
